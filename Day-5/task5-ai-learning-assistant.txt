PYTHON FUNCTIONS
----------------

me: Act as a programming teacher. Explain Python functions to me - what they are, why we use them, how they work. Keep it beginner friendly.

chatgpt: Sure! The best way to think about a function is like a recipe. You write the recipe once, give it a name, and then you can "cook" it as many times as you want without rewriting anything.

In Python:

def greet(name):
    return "Hello, " + name + "!"

print(greet("Adithya"))   # Hello, Adithya!
print(greet("Priya"))     # Hello, Priya!

You wrote greet once. You can call it with any name. That's the whole point.

Quick vocab:
- def: how you define a function
- name: the parameter (a placeholder for the actual value)
- return: sends a value back to whoever called the function

No parameters:
def say_hello():

Multiple parameters:

print(power(3, 3))  # 27

The last one - if you don't pass an exponent it defaults to 2. If you do pass one it uses that instead.

# exercise 1
def celsius_to_fahrenheit(c):
    return (c * 9/5) + 32

print(celsius_to_fahrenheit(0))    # 32.0
print(celsius_to_fahrenheit(100))  # 212.0
print(celsius_to_fahrenheit(37))   # 98.6

# exercise 2
def is_palindrome(s):
    s = s.lower()
    return s == s[::-1]

print(is_palindrome("Racecar"))  # True
print(is_palindrome("hello"))    # False

# exercise 3 - this took me a while. had to look up isinstance
def flatten_list(lst):
    result = []
    for item in lst:
        if isinstance(item, list):
            result.extend(flatten_list(item))
        else:
            result.append(item)
    return result

print(flatten_list([[1, 2], [3, [4, 5]], 6]))

APIS
----

me: Explain what an API is and how HTTP APIs work. Use a real world analogy.

chatgpt: Think of a restaurant. You sit down, look at the menu, tell the waiter what you want, and they bring it back. You never go into the kitchen yourself.

In this:
- you = the client (your app)
- the menu = the API documentation (what requests are available)
- the waiter = the API
- the kitchen = the server/database

The kitchen doesn't care who you are. It just receives orders and sends food. APIs work the same - they give applications a standardized way to request data or services.

HTTP APIs specifically:
1. your app sends a request to a URL
2. the request has a method (GET to read, POST to create, PUT to update, DELETE to remove)
3. server processes the request
4. server sends back a response with a status code and usually JSON data
5. your app reads the response

---

me: Show me how to call a real API in Python. One that doesn't need a key.

chatgpt: Use JSONPlaceholder - it's a free fake API for testing.

import requests

response = requests.get("https://jsonplaceholder.typicode.com/posts/1")

print(response.status_code)  # 200 = success
print(response.json())       # the response as a python dict

You'll get back something like:
{"userId": 1, "id": 1, "title": "...", "body": "..."}

Always check status_code before using the data. 200 = ok, 404 = not found, 500 = server error.

JSON
----

me: Explain JSON. What it is, the rules, why it's used everywhere.

chatgpt: JSON = JavaScript Object Notation. Don't let the name throw you off, it's used in basically every programming language.

It's just a text format for storing and sharing data. It became the standard because it's human readable and easy for machines to parse. Way simpler than what came before it (XML).

Rules:
- keys must be strings in double quotes
- values can be string, number, boolean (true/false), null, array, or another object
- arrays use [ ], objects use { }
- no trailing commas (this trips everyone up at some point)
- no comments

Example:
{
  "name": "Adithya",
  "age": 20,
  "skills": ["Python", "AI"],
  "active": true
}

In Python, json module:
- json.loads(string) → string to dict
- json.dumps(dict) → dict to string
- json.load(file) → file to dict
- json.dump(dict, file) → dict to file

The s stands for string. loads/dumps = string. load/dump = file.

# exercise 1
import json

json_str = '{"students": [{"name": "Alice", "score": 88}, {"name": "Bob", "score": 72}, {"name": "Carol", "score": 95}]}'

students = data["students"]

print(students[1]["name"])  # Bob

total = sum(s["score"] for s in students)
print(f"Average: {total / len(students)}")  # 85.0
